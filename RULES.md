# Правила проекта

## 1. О проекте
- **Название / Назначение**: Telegram Mini App расписания географического факультета БГУ.

## 2. Архитектура
- **Тип**: Static Serverless (HTML + Vanilla JS + CSS).
- **Сборщики**: Без Node.js сборщиков (без Vite, Webpack, npm-скриптов сборки и т.д.). Все файлы подключаются напрямую.

## 3. Хостинг
- **Платформа**: GitHub Pages.

## 4. Данные
- **Файл данных**: `schedule_data.json`.
- **Генерация**: Генерируется исключительно скриптом `build_schedule.py`.

## 5. Правила UI / Стилизация
- **Стиль оформления**: Liquid Glass (стеклянные поверхности, мягкие размытия, глубина, современные полупрозрачные акценты).
- **Производительность**: Стабильные 60–120 FPS (минимизация перерисовок/reflow, аппаратное ускорение `transform`, `opacity`, `will-change` при необходимости).
- **Технологии стилей**: Tailwind CSS + daisyUI (подключение через CDN) в сочетании с нативным CSS (Liquid Glass).
- **Ограничения**: Разрешено использование Tailwind CSS и daisyUI через CDN с обязательным кэшированием в Service Worker. Запрещены тяжелые сборщики (Webpack, Vite, npm-билд процессы) — проект остается Zero-Build Static Serverless. Подробные правила и соглашения описаны в `GEMINI.md`.
